# Comma-separated --disallowedTools list shared by every Claude invocation
# in the EA (Slack bot, run-agent.sh, run-plugin.sh, ea-bot-shell.sh,
# ea-resident-inner.sh).
#
# Everything listed here has EXTERNAL effect on a human — it sends mail,
# deletes mail, or creates/moves/cancels a meeting other people are on —
# AND is button-gated in the normal Slack-approval flow. The button-gate
# is enforced in code (confirm-tokens in graph_actions.py, the mediator
# in preprocessor/mail_mediation.py); this list is defense-in-depth so an
# LLM can never invoke them even if it has the right --allowedTools glob
# in scope.
#
# This list is the ONLY enforcement layer for the resident lane:
# scripts/ea-resident-inner.sh runs Claude with
# --dangerously-skip-permissions, where the allowlist is moot and only
# --disallowed-tools still applies. Anything omitted here is reachable.
#
# request-confirm is included because it mints tokens — without it on the
# deny list, an LLM with the graph_actions.py glob could chain
# request-confirm -> send-draft and bypass the Slack button entirely.
#
# Both `python3 *<script> <cmd>` and bare `*<script> <cmd>` variants are
# listed because the LLM could invoke a script either with or without an
# explicit python3 prefix.
#
# Lines starting with '#' are comments. The runtime concatenates all
# non-comment lines, strips whitespace, and joins with commas.
